## 2. 直近3ヶ月(2026年5月〜7月)の動きと要因分析

### 2-1. 全体の流れ

- **5月〜6月中旬:上昇局面。** AI・半導体の業績期待を背景に米株は最高値を更新し続け、S&P500は3月末から一時+14%超。日経平均も円安(1ドル=160円台)とAI関連物色を追い風に6月22日に72,831円の年初来高値をつけた。
- **6月上旬:最初の警告。** 6月5日にAI・半導体株が急落(SOX指数▲10.3%、S&P500情報技術▲5.8%)。過熱感と利益確定売りが引き金だが、この時点ではVIXは21程度にとどまり「調整」の範囲で反発。
- **7月:調整本格化。** 複数の悪材料が連鎖し、AI・半導体を中心に大きく崩れた。日経平均は7月17日に高値比▲11.4%の64,141円まで急落。米国でも半導体株が弱気相場入り。

### 2-2. 米国指数の変動要因

**支え(上昇要因)**
1. **好調な企業業績:** Q2決算シーズンで「レジリエント」な業績・ガイダンスが相次ぎ、指数全体の下値を支えた。
2. **利上げ観測の後退局面:** 6月雇用統計(7/2発表)が+5.7万人と予想(+11.3万人)を大幅に下回り、FRBの早期利上げ警戒が和らいだ。ウォーシュFRB議長の「インフレ期待低下」発言(7/1)も株買い材料に。
3. **中東の戦闘終結・原油反落:** 戦闘終結→交渉入りの局面ではリスク選好が回復。原油安の場面は景気懸念を和らげた。

**重石(下落要因)**
1. **AI投資の持続性への疑念:**
   - Anthropicの自社半導体開発報道(7/2、SOX約▲12%)
   - Metaがデータセンター計算能力を外部リースへ転換と報道(「AI投資過剰」の思惑)
   - OpenAIがIPOを2027年に延期検討との報道
2. **中国発AIショック(7/17):** 米最先端モデルに性能で肉薄し料金も安い中国製AIモデルの発表で、米AI企業の優位性に疑義。ナスダック▲1.4%(場中▲2%超)、半導体株が弱気相場入り。
3. **粘着的なインフレと「利上げ」リスク:** 5月CPIは前年比+4.2%と高止まり。市場は**年内2回の利上げ**を織り込む状況で、利下げではなく利上げが議論される異例の環境。
4. **中東情勢の再燃と原油高:** 7月には原油(WTI)が一時90ドル台に乗せる場面もあり、インフレ・景気の両面で重石。
5. **新たなグローバル関税:** 関税政策のヘッドラインが断続的に上値を抑制。

### 2-3. 日本指数の変動要因

**支え(上昇要因)**
1. **記録的な円安(1ドル=160〜163円台):** 輸出企業の収益期待を強力に下支え。高市政権下の財政運営への警戒後退も寄与。
2. **AI・半導体関連の物色:** 6月までは米ハイテク高に連動して指数を牽引。
3. **個人投資家の押し目買い:** 7/17の急落局面でも高配当株などに個人の買いが観測された。

**重石(下落要因)**
1. **米AI・半導体株安への高感応度:** 日経平均は半導体比率が高く、米国発の下げが増幅されて伝わった(7/2の米雇用統計ショック時は米株▲0.1%に対し日経▲2.5%)。
2. **円高への脆弱性:** 弱い米指標や日銀利上げ観測が出るたびに円高→輸出株売りの反応。
3. **日銀の利上げ観測と金利上昇:** 10年国債利回りは2.79%まで上昇。市場は**10月利上げを87%、12月までの利上げを100%**織り込み。バリュエーション(PERは2月の20.5倍→18倍前後へ)の圧縮要因に。
4. **ボラティリティの急拡大:** 7/3には一時▲1,100円超→終値+1,010円という乱高下。日経VI急騰が示す不安定な需給。

## 3. 今後の動向と注視すべき内容

### 直近の最重要イベント
| 日程 | イベント | 注目点 |
|---|---|---|
| **7/29-30** | **FOMC** | 据え置き予想(利上げ織り込み3割強)だが、ウォーシュ議長の「インフレを一切容認しない」姿勢が会見でどう出るか。タカ派ならドル高・株の重石 |
| **7/30-31** | **日銀金融政策決定会合** | 据え置きがほぼ確実。焦点は展望レポートと植田総裁会見。利上げペース「加速」が示唆されれば円高・株安要因 |
| 8月中旬 | 米7月CPI | +4%台の高止まりが続くか。上振れなら利上げ観測強化 |
| 随時 | 米大手テック決算 | AI投資(設備投資計画)の持続性と収益化の証拠 |

### 中期的に注視すべきテーマ
1. **AIバブル論争の行方:** 「決算は良いのに株が売られる」状態が続くか。中国AIとの競争、自社チップ化、計算資源の外部リース化など、AIハードウェアの収益構造を揺るがす材料の続報。
2. **米インフレとFRBの利上げ:** 年内2回の利上げ織り込みが現実になるか。利上げ実施なら株式バリュエーション全般に逆風。
3. **ドル円と為替介入リスク:** 163円台後半、市場では「170円へのカウントダウン」も意識される。一方で日銀利上げや中東収束で円高転換すれば日本株には二重の逆風(野村は年末152.5円を予想)。
4. **中東情勢と原油:** WTIが90ドル台に定着するとインフレ再加速→金融引き締め強化のリスク。
5. **関税政策:** 新たなグローバル関税の対象拡大・報復の有無。
6. **日本の長期金利:** 10年債2.8%前後からの一段の上昇は株式の相対的魅力を低下させる。
7. **需給・テクニカル:** 日経平均は高値比10%安の後、過去の類似局面では「景気後退ならさらに5%以上下落・1年間軟調」という経験則(野村分析)。景気後退の有無が分水嶺。

## 4. 数ヶ月先(〜2026年秋・年末)のシナリオ予測

> ※以下は公開情報に基づく一般的なシナリオ整理であり、投資助言ではありません。実際の投資判断はご自身の責任で行ってください。

### 🟢 良いシナリオ(強気)― 実現確率のイメージ:25〜30%
**条件:** Q2〜Q3決算でAI投資の収益化が確認され、中東が収束して原油が70ドル以下へ、CPIが鈍化してFRBの利上げが回避される。
- **米国:** S&P500は7,500超の最高値更新を再開。半導体株も反発し弱気相場から脱出。
- **日本:** 円が急激に動かず(155〜165円)、日経平均は70,000円台を回復、年初来高値(72,800円台)再トライも。
- **合図:** CPIの明確な鈍化、AI大手の設備投資計画の維持+利益率改善、VIX/日経VIの低下。

### 🟡 中間シナリオ(レンジ・もみ合い)― 実現確率のイメージ:40〜50%
**条件:** 業績は堅調だがAI懸念・インフレ・地政学が交互に材料視され、方向感が出ない。
- **米国:** S&P500は概ね **7,000〜7,500** のレンジ。ハイテクからバリュー・ディフェンシブへの資金ローテーションが進む。
- **日本:** 日経平均は **62,000〜70,000円** で乱高下。円安が下値を支えるが、日銀利上げ観測が上値を抑える。ボラティリティは高いまま。
- **合図:** 決算は良いが株価反応が鈍い状態の継続、金利・為替のレンジ推移。

### 🔴 悪いシナリオ(弱気)― 実現確率のイメージ:25〜30%
**条件:** ①中国AIとの競争激化や投資削減報道が続きAIバブル崩壊懸念が本格化、②原油高でインフレ再加速→FRBが実際に利上げ、③円高転換(日銀利上げ加速)が重なる。
- **米国:** S&P500は高値から15〜20%調整(**6,000台前半〜中盤**)。半導体・AI関連は一段安。
- **日本:** 円高+米株安のダブルパンチで日経平均は **55,000〜60,000円** 程度まで下落余地。過去の経験則どおり「景気後退を伴えば高値比▲16%超・1年軟調」の展開。
- **合図:** 米雇用の一段の悪化(景気後退シグナル)、AI大手の設備投資「削減」の明言、FRBの利上げ実施、ドル円の急激な円高(155円割れ)や逆に170円超の急激な円安(介入・混乱リスク)。

## 5. まとめ

- 直近3ヶ月は「**AI主導の最高値更新 → 7月のAI・半導体ショックによる急調整**」という流れ。米国は指数レベルでは軽傷、日本は▲11%超と重傷で、**震源は米国・被害は日本に大きい**構図。
- 最大の分岐点は、①**AI投資の持続性**(中国勢との競争・収益化)、②**FRBが実際に利上げするか**、③**日銀の利上げペースとドル円の方向**、の3点。
- 目先1週間(7/29-30 FOMC、7/30-31 日銀会合)が短期の方向を決める重要イベント。
